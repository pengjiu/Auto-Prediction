2. Support a deliberately bounded typed numeric dialect, with exact decimal thresholds, comparison, unit, observation source and interval. Unknown syntax/parameters, contradictory structured metadata, missing referenced policies and ambiguous rules stay research-only. No floating money, heuristic unit conversion or invented premise.
3. Bump compiler identity; recompile from current rule evidence instead of trusting old exact labels. Validate native binding and reject stale predicate artifacts. Rejection must downgrade previously exact predicates too.

Initially only common-observation numerical threshold families; include endpoints and open cells with exact arithmetic, mixed YES/NO and explicit exception scenarios. No second natural-language parser in Python. Bind IDs, rules and observations, retain ASSUMED_STATES_ONLY/RESEARCH_PROPOSAL_ONLY. This is not a certificate.
5. Feed the export into the existing S1 and same-depth S2 baselines. Reject unknown fees, missing/misaligned books, foreign units and unsupported semantics rather than create a profit result. Use historical genuine bytes only as explicitly retrospective evidence; synthetic supported cases must be clearly labeled synthetic. Do not promise positive real admission or current market profit.
